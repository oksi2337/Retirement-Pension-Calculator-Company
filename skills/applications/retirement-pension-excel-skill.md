# Retirement Pension DC Excel Skill

## 🎯 Purpose

퇴직연금 DC형 납입액 **계산기(웹)에서 산출된 결과 데이터**를 받아,
표준 양식의 **Excel 파일(.xlsx)** 로 정리하는 스킬.

> ⚠️ 이 스킬은 **계산을 수행하지 않는다.** 계산은 이미 완료되어 입력으로 들어온다고 가정한다.
> 본 스킬의 책임은 **"받은 데이터를 정해진 Excel 포맷으로 출력"** 하는 것에 한정된다.

---

## 📥 Input

### 필수 입력 데이터 (직원별)

| 항목 | 타입 | 예시 | 비고 |
|---|---|---|---|
| 성명 | 문자열 | "홍길동" | 필수 |
| 사번 | 문자열 | "EMP-2024-001" | 필수 |
| 생년월일 | 날짜 (YYYY-MM-DD) | "1990-05-15" | Sheet 1 전용 (Sheet 2에는 표기 안 함) |
| 입사일 | 날짜 (YYYY-MM-DD) | "2020-03-15" | 필수 |
| 퇴직일/기산일자 | 날짜 (YYYY-MM-DD) | "2026-04-30" | 필수 |
| 임금총액 (A) | 숫자 (원) | 65,400,000 | 1년치 합계 |
| 예상 납입액 | 숫자 (원) | 5,450,000 | A ÷ 12 |
| 기지급 납입액 | 숫자 (원) | 1,000,000 | 없으면 0 |
| 최종 납입액 | 숫자 (원) | 4,450,000 | round(예상 / 10) × 10 − 기지급 (1원자리 반올림, 10원 단위) |

### 상세 내역용 추가 데이터 (선택)

- **첫 달 보정 정보**: 방식(일할 안분 / 차감액 직접 입력) + 금액
- **마지막 달 보정 정보**: 방식 + 금액
- **과세별도기지급액 항목 리스트**: 각 항목명, 금액, 비일회성/일회성 구분
- **1년치 급여지급액 원본**: 보정 전 합계

### 입력 형식 (권장)

```json
{
  "employees": [
    {
      "name": "홍길동",
      "employee_id": "EMP-2024-001",
      "hire_date": "2020-03-15",
      "retirement_date": "2026-04-30",
      "annual_salary_raw": 66000000,
      "first_month_adjustment": {
        "method": "prorated",
        "amount": 200000
      },
      "last_month_adjustment": {
        "method": "manual_deduction",
        "amount": 400000
      },
      "additional_payments": [
        {"name": "성과급", "amount": 3000000, "type": "non_recurring", "include": true},
        {"name": "연차수당", "amount": 800000, "type": "recurring", "include": true},
        {"name": "특별 위로금", "amount": 500000, "type": "one_time", "include": false}
      ],
      "wage_total": 69200000,
      "expected_contribution": 5766667,
      "prepaid_contribution": 1000000,
      "final_contribution": 4766667
    }
  ]
}
```

> 💡 입력이 위 JSON 형식이 아니어도 괜찮다. 표/대화/스크린샷 등 어떤 형태로든 위 8개 필수 항목이 추출 가능하면 진행한다.

## 📤 Output

### 파일

- **형식**: `.xlsx` (Excel)
- **파일명 규칙**: `퇴직연금_DC_납입액_YYYYMMDD.xlsx` (오늘 날짜 기준)
- **저장 위치**: `/mnt/user-data/outputs/` (Claude 환경 기준)

### Sheet 1: 요약

전 직원의 납입액 집계 표.

| 컬럼 | 너비 | 포맷 |
|---|---|---|
| No | 6 | 정수 (가운데 정렬) |
| 성명 | 12 | 텍스트 (가운데 정렬) |
| 사번 | 14 | 텍스트 (가운데 정렬) |
| 생년월일 | 14 | `yyyy-mm-dd` (가운데 정렬) — Sheet 2에는 미표기 |
| 부서 | 16 | 텍스트 (가운데 정렬) |
| 임금총액 | 18 | `#,##0"원"` |
| 예상 납입액 | 18 | `#,##0"원"` |
| 기지급 차감 | 18 | `#,##0"원"` |
| 최종 납입액 | 20 | `#,##0"원"` (굵게) |
| 비고 | 28 | 텍스트 (가운데 정렬) |

**행 구성**:
1. 1행: 헤더 (굵게, 배경색 `#1F4E78` 진한 파랑, 글자색 흰색)
2. 2행~N행: 직원별 데이터
3. N+1행: **합계 행** (배경색 `#FFF2CC` 연노랑, 굵게)
   - "합계" 라벨 (B열 병합)
   - 임금총액·예상 납입액·기지급 차감·최종 납입액 각각 `=SUM(...)` 수식 사용

### Sheet 2: 상세 내역

직원별 블록 단위로 구성. 각 블록은 다음 구조:

```
┌─────────────────────────────────────────────┐
│ [블록 헤더] No.1 - 홍길동 (EMP-2024-001)    │  ← 굵게, 배경색 강조
├─────────────────────────────────────────────┤
│ 1. 기본 정보                                 │
│    - 입사일: 2020-03-15                      │
│    - 퇴직일/기산일자: 2026-04-30             │
│                                              │
│ 2. 임금총액 산출 내역                        │
│    - 1년치 급여지급액      66,000,000 원     │
│    - 첫 달 보정 (일할 안분)  -200,000 원     │
│    - 마지막 달 보정 (차감)   -400,000 원     │
│    - 비일회성 별도지급액    +3,800,000 원    │
│    ─────────────────────────────────         │
│    임금총액 (A)            69,200,000 원     │  ← 굵게
│                                              │
│ 3. 과세별도기지급액 항목                     │
│    [표: 항목명 | 금액 | 구분 | 포함여부]      │
│                                              │
│ 4. 산출 결과                                 │
│    - 예상 납입액 (A÷12)     5,766,667 원     │
│    - 10원 단위 반올림 조정          3 원     │  ← 값이 0이면 줄 생략
│    - 기지급 차감           -1,000,000 원     │
│    ─────────────────────────────────         │
│    최종 납입액              4,766,670 원     │  ← 굵게, 강조색
└─────────────────────────────────────────────┘
```

블록 사이에는 **빈 행 1줄** 삽입.

## 🎨 Style Rules

### 폰트
- 기본 폰트: **맑은 고딕 (Malgun Gothic)** 11pt
- 헤더: 동일 폰트 12pt 굵게
- 숫자 셀: 동일 폰트, 우측 정렬

### 색상 (산업 표준 + 가독성)
| 용도 | 색상 코드 | 비고 |
|---|---|---|
| 헤더 배경 | `#1F4E78` | 진한 파랑 |
| 헤더 글자 | `#FFFFFF` | 흰색 |
| 합계 행 배경 | `#FFF2CC` | 연노랑 (강조) |
| 블록 헤더 배경 | `#D9E1F2` | 연파랑 |
| 최종 납입액 강조 | 글자 굵게 + `#C00000` 진한 빨강 |
| 일반 셀 | 기본 흰색 |

### 숫자 포맷
- **금액**: `#,##0"원"` (천 단위 콤마 + "원" 단위)
- **날짜**: `yyyy-mm-dd`
- **0 표시**: 명시적으로 `"0원"`이 아닌 `"-"` 로 표시 (산업 표준 적용)

### 정렬
- 텍스트(성명, 사번, 항목명): **가운데** 또는 **좌측**
- 숫자: **우측 정렬**
- 헤더 행: **가운데**

### 테두리
- 모든 데이터 셀: 얇은 테두리 (회색 `#BFBFBF`)
- 합계 행: **위·아래 굵은 테두리** (검정)

### 컬럼 너비
- Sheet 1 요약: 위 표 참조
- Sheet 2 상세: A열(라벨) 24, B열(값) 20, C열(부가설명) 16

## 🛠️ Implementation Notes

### 사용 라이브러리
- **openpyxl** — 셀 단위 포맷팅과 수식 작성에 적합 (이 스킬의 주력)
- pandas는 사용하지 않음 (포맷팅 제어가 제한적)

### 핵심 코드 패턴

```python
from openpyxl import Workbook
from openpyxl.styles import Font, PatternFill, Alignment, Border, Side
from openpyxl.utils import get_column_letter
from datetime import datetime

# 1. 워크북 생성
wb = Workbook()

# 2. Sheet 1: 요약
ws_summary = wb.active
ws_summary.title = "요약"
# ... 헤더, 데이터, 합계 행 작성
# 합계는 반드시 수식으로: ws_summary['D{N+1}'] = f'=SUM(D2:D{N})'

# 3. Sheet 2: 상세 내역
ws_detail = wb.create_sheet("상세 내역")
# ... 직원별 블록 반복 작성

# 4. 저장
filename = f"퇴직연금_DC_납입액_{datetime.now().strftime('%Y%m%d')}.xlsx"
wb.save(f"/mnt/user-data/outputs/{filename}")
```

### ⚠️ 반드시 지킬 것

1. **합계는 항상 `=SUM()` 수식 사용** — 파이썬에서 더해서 하드코딩 ❌
2. **수식 작성 후 반드시 재계산 스크립트 실행**:
   ```bash
   python /mnt/skills/public/xlsx/scripts/recalc.py /mnt/user-data/outputs/파일명.xlsx
   ```
3. **수식 오류(#REF!, #DIV/0! 등) 0건** 검증 후 사용자에게 전달
4. **0 값 처리**: 기지급 차감이 0이어도 `0원`이 아닌 `-` 로 표시 (포맷 활용)

## 🚦 Edge Cases

| 케이스 | 처리 방식 |
|---|---|
| 직원 1명만 입력됨 | 정상 처리. 합계 행도 동일하게 생성. |
| 기지급 납입액이 0 또는 미입력 | 0으로 처리 후 셀 포맷에서 `-`로 표시 |
| 과세별도기지급액 항목이 없음 | Sheet 2의 "3. 과세별도기지급액 항목" 섹션에 *"해당 없음"* 표기 |
| 첫 달/마지막 달 보정이 없음 (만 1년 이상 근속) | Sheet 2의 산출 내역에서 해당 줄 생략 또는 `0원` 표기 |
| 입사일 > 퇴직일 (입력 오류) | **에러 발생** → 사용자에게 즉시 알리고 진행 중단 |
| 임금총액이 음수 | **에러 발생** → 입력 검토 요청 |
| 직원 100명 이상 대량 입력 | 정상 처리 가능. 다만 Sheet 2가 매우 길어지므로 사용자에게 사전 안내. |
| 한글이 깨지는 환경 | 폰트를 "Arial Unicode MS" 또는 "Noto Sans CJK KR"로 fallback |

## 💡 Usage Example

**입력 (사용자 메시지)**:
> "계산기에서 뽑은 직원 3명 결과인데 엑셀로 정리해줘.
> [데이터 첨부 또는 표 붙여넣기]"

**스킬 동작**:
1. 입력 데이터에서 직원별 8개 필수 항목 + 상세 항목 추출
2. openpyxl로 워크북 생성
3. Sheet 1 (요약) 작성 — 합계는 `=SUM()` 수식으로
4. Sheet 2 (상세 내역) 작성 — 직원별 블록 단위
5. 스타일 적용 (폰트, 색상, 테두리, 포맷)
6. `/mnt/user-data/outputs/`에 저장
7. `recalc.py` 실행하여 수식 검증
8. 오류 0건 확인 후 사용자에게 파일 전달 (`present_files`)

**출력**:
- ✅ `퇴직연금_DC_납입액_20260425.xlsx`
- ✅ 짧은 요약 코멘트 (직원 수, 총 납입액 합계)
